# LAXMTB Race Results & Start Lists Dashboard

Live race tracking and start lists dashboard for local area mountain bike teams (La Crosse Central, La Crosse Logan, La Crosse Aquinas, La Crosse Composite, La Crescent, and Holmen).

## Features
- **Live Sync**: Automatically fetches data in real-time from the official RACE RESULT API.
- **Race Day Live Results**: Automatically streams lap times and finish results as riders cross timing mats.
- **2026 Wave & Staging Schedule**: Accurate wave times, staging grid call-ups, and pre-ride windows synchronized with the official race schedule.
- **Stage & Wave Notifications**: Real-time reminders for upcoming staging/race starts (configurable 30, 15, 5, or custom minutes prior) with subscriptions for categories, waves, or individual riders via browser notifications, audio chimes, and in-app toasts.
- **Wave & Category Filter**: Filter by categories (Varsity, JV, Freshman, Middle School) and waves.
- **Instant Search**: Search by rider name, plate number, bib, or school.
- **Mobile-First Responsive UI**: Compact navigation menu, locked brand typography, dark/light theme switching, and offline/online status monitoring.
- **Print & Venue Friendly**: Optimized for on-course viewing at the race venue and for clean physical printing.
